## Settings

Access these settings by clicking on the **Settings** icon, which is grey and looks like a gear inside of a circle.

- [ ] Make the desktop icons small
  - [ ] Settings -> Ubuntu Desktop -> Desktop Icons section -> Size -> Small
- [ ] Cause adding new desktop icons to appear in the top left corner
  - [ ] Settings -> Ubuntu Desktop -> Desktop Icons section -> Position of New Icons -> Top Left
- [ ] Do not show the Home folder as a desktop icon
  - [ ] Settings -> Ubuntu Desktop -> Desktop Icons section -> Show Home Folder -> Off
- [ ] Move the dock from the left side to the bottom
  - [ ] Settings -> Ubuntu Desktop -> Dock section -> Icon Size -> 30
  - [ ] Settings -> Ubuntu Desktop -> Dock section -> Position on Screen -> Bottom
- [ ] Enable the appropriate number of workspaces - in most cases this will be four
  - [ ] Settings -> Multitasking -> Workspaces section [scroll down a bit] -> Fixed Number of Workspaces -> 4
- [ ] Make Strawberry the Default Music Player
  - [ ] Settings -> Apps -> Default Apps -> Music -> Strawberry
- [ ] Set up Konsole to Auto-start
  - [ ] Settings -> Apps -> Konsole -> Autostart -> Turn it on
- [ ] Turn off the Lock Screen
  - [ ] Settings -> Privacy & Security -> System section -> Screen Lock -> Automatic Screen Lock -> Turn it OFF
  - [ ] Settings -> Privacy & Security -> System section -> Screen Lock -> Lock Screen Notifications -> Turn it OFF
  - [ ] Settings -> Privacy & Security -> System section -> Screen Lock -> Lock Screen on Suspend -> Turn it OFF
- [ ] Set the Time Format to AM/PM
  - [ ] Settings -> System -> Date & Time -> Time Format -> AM/PM
