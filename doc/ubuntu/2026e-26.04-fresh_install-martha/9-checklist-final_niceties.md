## Settings

Access these settings by clicking on the **Settings** icon, which is grey and looks like a gear inside of a circle.

- [X] Enable the appropriate number of workspaces - in most cases this will be four
  - [X] Settings -> Multitasking -> Workspaces section [scroll down a bit] -> Fixed Number of Workspaces -> 4
- [X] Make the desktop icons small
  - [X] Settings -> Ubuntu Desktop -> Desktop Icons section -> Size -> Small
- [X] Cause adding new desktop icons to appear in the top left corner
  - [X] Settings -> Ubuntu Desktop -> Desktop Icons section -> Position of New Icons -> Top Left
- [X] Do not show the Home folder as a desktop icon
  - [X] Settings -> Ubuntu Desktop -> Desktop Icons section -> Show Home Folder -> Off
- [X] Move the dock from the left side to the bottom
  - [X] Settings -> Ubuntu Desktop -> Dock section -> Icon Size -> 30
  - [X] Settings -> Ubuntu Desktop -> Dock section -> Position on Screen -> Bottom
- [X] Make Strawberry the Default Music Player
  - [X] Settings -> Apps -> Default Apps -> Music -> Strawberry
- [X] Set up Konsole to Auto-start
  - [X] Settings -> Apps -> Konsole -> Autostart -> Turn it on
- [X] Turn off the Lock Screen
  - [X] Settings -> Privacy & Security -> System section -> Screen Lock -> Automatic Screen Lock -> Turn it OFF
  - [X] Settings -> Privacy & Security -> System section -> Screen Lock -> Lock Screen Notifications -> Turn it OFF
  - [X] Settings -> Privacy & Security -> System section -> Screen Lock -> Lock Screen on Suspend -> Turn it OFF
- [X] Set the Time Format to AM/PM
  - [X] Settings -> System -> Date & Time -> Time Format -> AM/PM
