Much of this is quite straightforward, answering several easy no-brainer questions that do not require further comment.

Following is a list of steps, for future reference, even when it's simple, but has been a while since the last time I did this:

- [ ] Shutdown the PC
- [ ] Disconnect all external USB storage drives
- [ ] Use the USB drive to boot the PC
  - [ ] May need to go into the PC's BIOS to get it to boot from the USB drive

  - [ ] May need to use the PC make and model to search the web for the PC's manual to figure this out
  - [ ] May need to use the original wired keyboard or mouse or both that came with the PC
